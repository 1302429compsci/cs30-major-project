# Major Project Proposal

## Description

A chaos focused rpg multiplayer monster battler where players can join a lobby together, and fight progressively more difficult waves of monsters together until everyone inevitably dies. Players can pick a multitude of different roles on the team to try and help their team keep the run going as long as possible. The map is randomly generated each round as to keep things fresh, with many different options of map tiles that have unique interactions with the players and their abilities.

## Needs To Have List

- multiplayer, with a hosted lobby system, where the host can decide how many players per lobby and start whenever they choose
- multiple player roles (akin to rpg classes, such as wizard, fighter, etc) that all have different gimmicks
- a select screen where the role you play can be selected
- a working monster ai that doesn't get stuck on everything and can target players
- multiple kinds of creatures to fight, each with different attacks, health, and resistances
- a wave system that progressively makes encounters more difficult over time
- some way to differentiate all the different players
- wizards should have more fleshed out spellcasting, with the ability to select what kind of spell targeting they'd like (line, AoE, self, etc) along with the spell itself
- more options for tiles spawning on the map

## Nice To Have List

- some kind of currency for skins and character customization, to further differentiate players
- player bots that can be added to a match
- different gamemodes, such as a gamemode where a player can control the monsters against other players
- difficulties to determine how fast the waves scale in power
- it would be really funny to have the spellbook of the wizard be evil and shuffle around the spellcasting options to mess with the player trying to cast spells
- along with that it would be really funny if all roles had a version of this for their abilities
- wave modifiers to make certain waves have different bonuses or negatives for the players
- roguelike elements that slowly allow the players to keep up with the constant increase in wave difficulty
